Плашка-вердикт: вывод о прогоне или токене простыми словами, а за ней — одна фраза «почему».

| Тон | Класс | Что значит |
|---|---|---|
| можно доверять | `te-tag--ok` | результат надёжен |
| есть оговорки | `te-tag--mid` | результат верен, но рядом были другие исходы |
| полагаться нельзя | `te-tag--low` | результат случаен или неустойчив |
| вручную | `te-tag--manual` | «Вставлено вручную» |
| нет данных | `te-tag--none` | «Нет данных» |

Тон значит одно и то же во всех разделах, а слова у каждого раздела свои — по одной формулировке на тон:

| Что оценивается | ok | mid | low |
|---|---|---|---|
| Токен | «Уверенный выбор» | «Лидер, но были варианты» | «Выбран не лидер» |
| Ответ в «Разговоре» | «Уверенный ответ» | «Есть сомнения» | «Ответ ненадёжен» |
| Выбор из вариантов | «Уверенный выбор» | «Есть сомнения» | «Ответ ненадёжен» |
| Сравнение | «Модели согласны» | «Согласны, но уверены по-разному» | «Модели расходятся» |
| Вычёркивание | «Ответ устойчив» | «Ответ опирается на несколько предложений» | «Ответ держится на одном предложении» |
| Внутри модели | «Определилась рано» | «Определилась к последним слоям» | «Колебалась до последнего слоя» |

- Всегда в строке `te-verdict`: плашка, затем объяснение цветом `muted` с конкретным числом.
- Потребитель передаёт тон и число; формулировку берёт из таблицы своего раздела, а не сочиняет. Новый раздел сначала добавляет строку в таблицу.
- Плашка стоит первой в разборе — раньше цепочки этапов и списков.
- Цвет не единственный носитель смысла: слова обязательны.

## Пример

```tsx
<Verdict tone="mid" label="Есть сомнения">Ближайший соперник <b>груша</b> имел 26%.</Verdict>
<VerdictTag tone="ok">Уверенный выбор</VerdictTag>
```
