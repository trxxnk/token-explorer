Поле запроса и строка частых параметров под ним.

- `te-composer` — поле и одна главная кнопка (`↑`; во время генерации — «Стоп»).
- `te-params` — чипы `te-param`: название и текущее значение жирным. Клик раскрывает под чипом одно `Field` с объяснением; `aria-expanded` отмечает открытый.
- В строке не больше четырёх чипов, и только то, что меняют между прогонами: температура, шаг генерации, набор сэмплеров. Остальное — в `SettingsPanel`.
- Чип показывается, только если подключённая модель этот параметр учитывает.
- Справа — подсказка о клавише (`te-kbd`).
- Потребитель передаёт список параметров раздела (название, значение, поле, объяснение) и обработчик отправки.
- В разделе с конструктором («Выбор из вариантов») поле заменяется свёрнутой формой, а строка параметров остаётся той же.

## Пример

```tsx
<Composer value={text} onChange={setText} onSend={send} busy={busy} onStop={stop} />
<ParamBar open={open} onToggle={setOpen} hint={<><Kbd>Tab</Kbd> — продолжить ответ</>}
  params={[{ id: 't', label: 'Температура', value: '0.80', editor: <Field …>…</Field> }]} />
```
