Таблица-теплокарта: числа «строка × условие», где насыщенность ячейки повторяет величину.

- `table.te-heat`; ячейка получает `data-l="1…4"` → `scale-1`…`scale-4` (до 15%, 15–30%, 30–50%, больше 50%).
- Один оттенок, меняется только плотность; число в ячейке всегда написано. Красно-зелёную шкалу не используй.
- `td.is-top` — итоговый победитель: жирный и контур `accent`.
- Над таблицей — вывод одной фразой («Ответ зависит от порядка…»): сначала ответ, потом числа.
- Шире контейнера — оборачивай в `te-scroll`.
- Потребитель передаёт заголовки столбцов, строки и значения 0–1.
- Подходит для проверки устойчивости, сравнения моделей, будущих «слой × токен». Для одного ряда чисел бери `CandidateRow`.

## Пример

```tsx
<HeatTable columns={['Вариант', 'на 1-м месте', 'на 2-м месте', 'в среднем']}
  rows={[{ label: 'C. морковь', values: [0.44, 0.36, 0.31], top: 2 }]} />
```
