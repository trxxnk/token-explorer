Раздел «Выбор из вариантов» в каркасе: карточка прогона с этапами, вариантами и проверкой устойчивости, внизу — свёрнутый конструктор запроса.

- Скелет тот же, что в «Разговоре»: запрос внизу → `RunCard` в ленте → разбор по клику.
- Конструктор — `Card raised` в зоне `dock`: в свёрнутом виде вопрос и «Запустить», в развёрнутом — поля вопроса и вариантов (`Field`, `Button variant="dashed"`).
- «Проверить устойчивость» добавляет в ту же карточку блок с `HeatTable`, а не открывает новый экран.
