Знак Token Explorer: развилка. Толстая линия снизу — путь ответа; в точке выбора он уходит по одной ветке (выбранный токен), а две тонкие и бледные — кандидаты, которые модель могла взять вместо него.

- `token-explorer-app-icon.svg` — значок приложения и вкладки: знак на плашке `#212121` со скруглением, выбранная ветка `#5AA9FF`, остальное `#ECECEC`.
- `token-explorer-app-icon-light.svg` — то же на белой плашке, монохромно `#212121`.
- `token-explorer-mark-on-dark.svg` — знак без плашки для тёмного фона: ветки и точка `#ECECEC`, выбранная ветка `#5AA9FF`.
- `token-explorer-mark-on-light.svg` — знак без плашки для светлого фона: ветки и точка `#212121`, выбранная ветка `#5AA9FF`.

Внутри интерфейса используй компонент `Mark`: он берёт цвета из темы (выбранная ветка — `accent`, остальное — `ink`). Файлы — для мест вне интерфейса: значок вкладки, README, обложки.

Не меняй число веток и их толщину, не перекрашивай в цвета состояний. Свободное поле вокруг — не меньше толщины выбранной ветки.
