Будущий раздел «Вычёркивание»: какие предложения текста решили исход. Собран из существующих компонентов.

- Вывод и одна цифра: на каком предложении держится ответ и какой у него шанс сейчас.
- `StageChain` из трёх шагов объясняет метод: весь текст → без одного → сравнение.
- Текст — `Answer` с `TokenChip`, где единица подсветки — предложение; клик вычёркивает его.
- Список — `CandidateList wrap`: строка — предложение, полоса — шанс ответа без него, сдвиг — в процентных пунктах со знаком.
- Единственный переключатель в шапке — единица вычёркивания.
