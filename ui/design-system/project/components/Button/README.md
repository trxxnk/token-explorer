Кнопка действия: одна главная на экран, остальные — тихие.

| Вид | Класс | Когда |
|---|---|---|
| Главная | `te-btn te-btn--primary` | «Запустить», отправка запроса. Одна на экран. |
| Обычная | `te-btn` | Действия раздела: «Другой вариант», «Настройки». |
| Малая | `te-btn te-btn--sm` | Действия под прогоном: «Продолжить», «Копировать». |
| Пунктирная | `te-btn te-btn--dashed` | Добавить элемент в список: «+ вариант». |
| Ссылка | `te-btn te-btn--link` | Раскрыть подробности рядом с заголовком блока. |
| Значок | `te-btn--icon` | Квадрат 38px; обязателен `aria-label`. |
| Стоп | `te-btn--danger` | Только остановка генерации и удаление. |

Потребитель задаёт подпись, обработчик и `disabled`. Подпись — глагол или «глагол + объект», без точки. Знак Юникода ставь перед подписью. Текст на заливке — `on-accent`.

`disabled` — только пока действие занято или уже выполнено («✓ Проверено»). Действие, которого модель не умеет, не показывай.

## Пример

```tsx
<Button variant="primary" onClick={run}>Запустить</Button>
<Button size="sm" onClick={reroll}>↻ Заново отсюда</Button>
<Button variant="primary" icon aria-label="Отправить">↑</Button>
```
