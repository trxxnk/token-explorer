Знак продукта: три убывающих столбика — выбранный токен и два кандидата, которые модель могла взять вместо него.

- Разметка: `<span class="te-mark" aria-hidden="true"><i></i><i></i><i></i></span>`; малый размер — `te-mark--sm` (13px) рядом с именем модели над ответом.
- Вместе с названием — блок `te-brand`: название стилем `title`, подпись стилем `hint` цветом `muted`.
- Высокий столбик — `ink`, два ниже — `accent`. Не перекрашивай, не меняй число столбиков, не ставь знак на заливку `accent`.
- Вне интерфейса бери файлы из группы «Logos».

## Пример

```tsx
<Brand title="Token Explorer" tagline="что модель могла сказать иначе" />
<Mark size="sm" />
```
