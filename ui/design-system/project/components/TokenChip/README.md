Токен в тексте ответа и его плашки: подсветка сомнений, вставленный вручную, служебный.

- `te-tok` внутри `te-answer` (шрифт с засечками). Подсветка — `data-heat="1…4"`, заливки `heat-1`…`heat-4`; без атрибута фона нет.
- Ступень подсветки потребитель считает сам: чем ниже шанс выбранного токена, тем выше ступень.
- `te-tok--manual` — токен, вставленный пользователем: `accent-soft` и подчёркивание `accent`.
- `te-tok--special` — служебный токен моноширинным в рамке; показывается только если включено в настройках.
- `te-code` — токен вне текста (шапка панели); `te-badge` — пометка ветки над ответом.
- Наведение и фокус — контур `accent` 1.5px; наведение открывает карточку, клик — панель (`Popover`).
- Пробел в начале токена показывай точкой `·`. Сравнивай токены по идентификатору, а не по виду.

## Пример

```tsx
<Answer>
  Выбор названия <TokenChip heat={2} onClick={() => open(7)}>зависит</TokenChip> от того…
</Answer>
```
