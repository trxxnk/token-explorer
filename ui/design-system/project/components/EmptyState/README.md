Пустое состояние раздела: что здесь можно узнать, три шага и готовые примеры запроса.

- Заголовок стилем `display` — вопрос, на который отвечает раздел; одно слово можно подсветить как токен.
- Одно предложение пояснения цветом `muted`.
- `te-how` — ровно три шага: действие жирным и следствие одной фразой.
- `te-chips` — два–четыре примера; клик подставляет запрос.
- Потребитель задаёт заголовок, шаги и примеры. Каждый новый раздел обязан иметь своё пустое состояние по этому же шаблону.
- Если модель не подключена — над заголовком `te-note` с кнопкой «Выбрать модель», а не отдельный экран.

## Пример

```tsx
<EmptyState title="Что модель могла сказать иначе" lead="Задайте вопрос…"
  steps={[{ title: 'Спросите', text: 'Модель ответит как обычно.' }, …]}
  examples={['Придумай название для кофейни']} onExample={setQuery} />
```
