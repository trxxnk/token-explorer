Плитка показателя: подпись, число и строка «что это значит».

- `te-tiles` — сетка из трёх плиток `te-tile`: `small` — название, `b` — значение (`metric-sm`), `i` — расшифровка простыми словами.
- Третья строка обязательна. «≈ 23» без «равных вариантов» — не показатель.
- Не больше трёх плиток на карточку. Четвёртый показатель — повод убрать один в подробности.
- Потребитель передаёт три строки на плитку и, если нужно, длинное объяснение для `title`.
- Плитка не кликается и не несёт цвета состояния: вывод делает `VerdictTag`.

## Пример

```tsx
<MetricTiles>
  <MetricTile label="Неопределённость" value="≈ 23" note="равных вариантов" />
</MetricTiles>
```
