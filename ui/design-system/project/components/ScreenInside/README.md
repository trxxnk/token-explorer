Будущий раздел «Внутри модели»: на каком слое модель определилась с токеном и на какие слова смотрела. Собран из существующих компонентов.

- Вывод: «Определилась рано» и номер слоя — простыми словами, без терминов.
- Вид «По слоям»: `StageChain` (начало → выбор → решение) и `HeatTable` «слой × кандидат»; контуром отмечен слой, где появился лидер.
- Вид «Куда смотрела»: исходный вопрос с подсветкой `TokenChip` по доле внимания и список `CandidateRow` по словам.
- Переключатель видов — единственный элемент управления в шапке.
- Раздел показывается только для моделей со своего сервера: остальные таких данных не отдают.
