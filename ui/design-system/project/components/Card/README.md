Карточка — поверхность `panel` с контуром `line` для одного смыслового блока; заметка — строка-предупреждение.

- `te-card`: шапка `te-card__head` (заголовок `te-cap` и, при необходимости, ссылка справа), затем содержимое. Блоки внутри разделяются `space-12`.
- `te-card--raised` добавляет `shadow-raised` — только для поля запроса и конструктора внизу экрана.
- Карточки не вкладывай друг в друга. Внутри карточки утопленные блоки делай на `panel2` (`MetricTile`, формула).
- `te-note` — предупреждение на `hot-soft` с одним действием справа; `te-note--err` — ошибка. Текст говорит, что случилось и что сделать.
- Цветную полосу слева у карточки не рисуй.

## Пример

```tsx
<Card title="Проверка устойчивости" action={<Button variant="link">как это считается</Button>}>…</Card>
<Note action={<Button size="sm">Выбрать другую</Button>}>Модель не отдаёт вероятности токенов.</Note>
```
