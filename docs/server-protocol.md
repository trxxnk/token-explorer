# Протокол своего сервера

Сервер: `server.py`, по умолчанию `http://127.0.0.1:8090`. CORS открыт для всех источников.

## GET /v1/models

Список найденных моделей в формате OpenAI: `{"object":"list","data":[{"id":"Qwen3.5-0.8B-8bit","object":"model"}]}`. Идентификатор — имя папки модели.

## GET /info

`{"engine":"token-explorer","protocol":1,"backend":"mlx","model":"...","layers":24}`. По полю `engine` страница узнаёт, что открыта с этого сервера.

## POST /generate

Тело — JSON. Ответ — поток SSE: строки `data: {...}`, в конце `data: [DONE]`.

### Запрос

| Поле | Тип | Смысл |
|---|---|---|
| `model` | строка | имя папки модели; другая модель загружается вместо текущей |
| `messages` | массив `{role, content}` | диалог; шаблон чата применяет сервер |
| `prompt` | строка | готовый текст промпта вместо `messages` (служебные токены распознаются) |
| `thinking` | bool | включить размышления в шаблоне, по умолчанию `true` |
| `prefix` | массив | начало ответа, которое нужно продолжить: числа — id токенов, строки — текст |
| `force` | массив | токены, которые подаются вместо сэмплинга и возвращаются с полной статистикой |
| `max_tokens` | число | сколько токенов сэмплировать; `0` вместе с `force` — только оценка текста |
| `n_probs` | число | сколько кандидатов возвращать |
| `temperature`, `top_k`, `top_p`, `min_p`, `repeat_penalty` | числа | сэмплеры; `top_k: 0` — выключен, `temperature: 0` — всегда самый вероятный |
| `seed` | число | неотрицательный — воспроизводимый сэмплинг |

`prefix` в ответе не повторяется, `force` — повторяется событиями `token` с `forced: true`. Так альтернативный кандидат или свой текст получают вероятности.

### События

**`start`**

```json
{"type":"start","model":"Qwen3.5-0.8B-8bit","prompt_tokens":48,"cached_tokens":47,
 "think_open":false,"load_s":0.0,"prompt_s":0.02}
```

`cached_tokens` — сколько токенов взято из кэша. `think_open: true` означает, что шаблон сам открыл блок `<think>` и модель начнёт с размышлений.

**`token`**

```json
{"type":"token","id":33477,"t":"ый","p":0.222,"q":0.1812,"rank":2,"H":1.8,"n":[40,5,3],
 "top":[{"id":42317,"t":"ое","p":0.6117,"q":0.7708},
        {"id":48933,"t":"ые","p":0.02388,"cut":"min_p"}]}
```

| Поле | Смысл |
|---|---|
| `id`, `t` | id и текст токена. `t` пуст, если токен обрывается посреди символа; тогда весь символ придёт со следующим токеном |
| `p` | вероятность у модели, до сэмплеров |
| `q` | фактический шанс после сэмплеров |
| `cut` | вместо `q`: сэмплер, отсёкший токен (`top_k`, `top_p`, `min_p`) |
| `rank` | место во всём словаре, с 1 |
| `H` | энтропия полного распределения, бит |
| `n` | число кандидатов после top-k, top-p, min-p |
| `top` | лучшие кандидаты по `p`, у каждого `q` или `cut`; выбранный токен добавляется, даже если он не в топе |
| `forced` | токен подан через `force` |
| `eos` | токен конца ответа; после него генерация останавливается |

Числа округлены до 4 значащих цифр.

**`done`**

```json
{"type":"done","reason":"stop","tokens":25,"tps":35.7}
```

`reason`: `stop` — модель выбрала токен конца, `length` — исчерпан `max_tokens`, `abort` — клиент отключился.

### Ошибки

До начала потока — обычный JSON-ответ с кодом 400 или 500: `{"error":{"message":"..."}}`. После начала — событие `data: {"error":{"message":"..."}}`.

### Примеры

Сгенерировать ответ:

```bash
curl -N localhost:8090/generate -d '{"messages":[{"role":"user","content":"Привет"}],"thinking":false,"max_tokens":20}'
```

Оценить готовый текст, ничего не генерируя:

```bash
curl -N localhost:8090/generate -d '{"messages":[{"role":"user","content":"Привет"}],"thinking":false,"force":["Здравствуйте!"],"max_tokens":0}'
```
