Настройки — редкое: серверы, диалог, отображение, данные; по вкладке на тему и не больше пяти полей на вкладке.

| Вкладка | Что в ней |
|---|---|
| Серверы | Адреса, состояние каждого и что он даёт; добавить сервер |
| Диалог | Системный промпт, размышления перед ответом |
| Отображение | Число кандидатов, порог подсветки, служебные токены |
| Данные | Импорт и экспорт чатов и прогонов, очистка истории |

- Открывается в рабочей области вместо раздела, а не боковой панелью поверх него.
- Вкладки — `Segmented`; строка сервера `te-server`: точка состояния, имя, адрес, фраза о возможностях.
- Параметров генерации (температура, Top-K, Top-P, шаг) здесь нет — они в `ParamBar`.
- Настройку, которая ничего не меняет для подключённой модели, не показывай. Пояснений «в этом режиме не используется» быть не должно.
- Новая функция добавляет поле в подходящую вкладку; шестое поле на вкладке — сигнал вынести параметр в раздел или убрать.
- Потребитель передаёт вкладки и поля (`Field`); каждое поле обязано иметь объяснение.

## Пример

```tsx
<SettingsPanel tab={tab} onTab={setTab} tabs={[{ value: 'servers', label: 'Серверы' }, …]}>

</SettingsPanel>
```
