Строка турнирной таблицы: место, кандидат, полоса, шанс и сдвиг к прошлому этапу.

Одна строка для всех разделов. Колонки: `te-row__rank` · `te-row__label` · `te-row__bar` · `te-row__pct` · `te-row__delta` · `te-row__go`.

- Список `te-rows`; над ним при необходимости шапка колонок `te-rows__cap`.
- Токены — `code.te-row__label` (моноширинный). Варианты ответа — список `te-rows--option`: вместо места метка `te-lb`, подпись без моноширинного.
- `is-chosen` — выбранный: полоса `ink`, шанс жирным, знак `✓`.
- `is-rest` — свёрнутый хвост «ещё N ток.»: серое, раскрывается по клику.
- `is-cut` — отсечён на этом этапе: зачёркнут, вместо шанса причина («✕ top-p»).
- Сдвиг — `is-up` (`ok`, знак +) или `is-dn` (`hot`, знак −); знак обязателен.
- Ширина полосы — доля от лидера на этом этапе, а не от 100%: так различимы и малые шансы.
- Строка-кнопка (`button.te-row`) создаёт ветку от кандидата; неинтерактивная — `div.te-row`.
- Потребитель передаёт упорядоченный список; при смене этапа меняет ширину и порядок — переход `t-bar` показывает, кто поднялся.
- В строке не больше одной полосы и двух чисел. Всё остальное — в `MetricTile`.

## Пример

```tsx
<CandidateList caption={['место', 'шанс (к прошлому этапу, п.п.)']}>
  <CandidateRow rank={1} label="·атмос" share={0.325} scale={0.325} delta={1.5} state="chosen" />
  <CandidateRow rank={2} label="·ваша" share={0.26} scale={0.325} delta={1.2} onPick={() => branch('·ваша')} />
  <CandidateRow label="·ко" share={0} state="cut" cutReason="top-p" />
</CandidateList>

<CandidateList options>
  <CandidateRow letter="A" label="яблоко" share={0.38} scale={0.38} state="chosen" />
</CandidateList>
```
