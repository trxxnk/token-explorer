Выбор модели: чип в шапке и список моделей по видам, где у каждой написано, какие разделы она умеет.

- `te-modelchip` — точка состояния (`te-dot--ok` / `te-dot--err`), имя модели, вид и источник. Клик открывает `te-models`.
- Список сгруппирован по виду: «Языковые модели», «Модели решений», «Модели эмбеддингов». Строка `te-model`: имя, источник, ниже — доступные разделы через «·».
- Ограничение пиши словами в той же строке («без разбора по этапам»), а не значком.
- Слова «протокол» здесь нет: способ подключения приложение определяет само при опросе серверов.
- По умолчанию показывай модели, которые умеют текущий раздел; остальные — под ссылкой «все модели».
- После выбора модели в `AppShell` остаются только её разделы.
- Адреса серверов — по ссылке внизу, в `SettingsPanel`.
- Потребитель передаёт каталог: имя, вид, источник, состояние, список разделов.

## Пример

```tsx
<ModelChip name="Qwen3.5-0.8B-8bit" kind="языковая · свой сервер" onClick={toggle} />
<ModelPicker current={id} onPick={setId} summary="Найдено на 2 серверах" groups={[
  { label: 'Языковые модели', models: [{ id: 'qwen', name: 'Qwen3.5-0.8B-8bit', source: 'свой сервер',
    sections: ['Разговор', 'Выбор из вариантов'] }] },
]} />
```
