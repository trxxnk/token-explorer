Переключатель между двумя–пятью взаимоисключающими видами одного и того же.

- `te-seg` — вид на содержимое раздела (подсветка, вкладки настроек). Выбранный пункт залит `accent`, текст `on-accent`.
- `te-seg te-seg--quiet` — частый параметр рядом с полем ввода (шаг генерации). Выбранный пункт — `accent-soft` и `accent-ink`.
- Потребитель задаёт пункты, выбранный и `aria-label` группы. Состояние — `aria-pressed`.
- Подписи — одно слово. Больше пяти пунктов — это уже список, бери `Field` с выпадающим списком.
- Навигацию по разделам переключателем не делай — для неё `AppShell`.

## Пример

```tsx
<Segmented label="Подсветка" value={heat} onChange={setHeat}
  options={[{ value: 'off', label: 'Нет' }, { value: 'uncertain', label: 'Сомнения' }]} />
```
