Полная панель токена: шаблон «разбор» целиком в одной всплывающей панели.

Порядок сверху вниз — от ответа к подробностям, и он один для всех разделов:

1. Шапка: номер, токен, главная цифра.
2. `VerdictTag` с фразой «почему».
3. `StageChain` с объяснением выбранного этапа.
4. Список `CandidateRow` для этого этапа.
5. Три `MetricTile`.
6. Действия: свой текст, «Заново отсюда».

- Собирается из `Popover` (`te-pop--panel`); своих стилей у панели нет.
- Потребитель передаёт токен, этапы и кандидатов; кандидаты сверх сохранённых подгружаются при раскрытии строки «ещё N».
- Высота не меняется при смене этапа: объяснение — `h-explain`, список кандидатов — фиксированное число строк с прокруткой.
- Любое действие создаёт ветку, исходный ответ остаётся — об этом говорит строка внизу.

## Пример

```tsx
<TokenPanel index="№10" token="·атмос" value="27%"
  verdict={<Verdict tone="mid" label="Лидер, но были варианты">…</Verdict>}
  stages={stages} active={stage} onStage={setStage} onPlay={play} onClose={close}
  tiles={<MetricTiles>…</MetricTiles>} actions={…} note="…">
  <CandidateList height={226}>…</CandidateList>
</TokenPanel>
```
