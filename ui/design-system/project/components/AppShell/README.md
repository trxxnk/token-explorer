Каркас приложения: колонка разделов с историей, шапка с моделью и рабочая область с запросом внизу. В превью — раздел «Разговор».

| Зона | Класс | Что в ней |
|---|---|---|
| Колонка | `te-rail` | Знак, разделы (`te-nav`), история текущего раздела (`te-hist`), внизу — «Настройки» и «Импорт и экспорт» |
| Шапка | `te-top` | Слева `ModelPicker`, справа — один переключатель вида, свой у раздела |
| Рабочая область | `te-body` | Лента `te-thread` из `RunCard` либо `EmptyState` |
| Низ | `te-dock` | `ParamBar` или конструктор запроса |

- Разделы — это задачи: «Разговор», «Выбор из вариантов», «Сравнение», «Вычёркивание», «Внутри модели». Текущий — `aria-current="page"`; справа у пункта — число сохранённых прогонов.
- Список рассчитан на шесть–семь строк. Раздел, которого модель не умеет, в нём отсутствует.
- Кнопок «+ Чат» и «+ Решение» нет: новый прогон начинается с поля внизу, новый разговор — первой строкой истории.
- В шапке справа не больше одного элемента управления. Второй — уже параметр, ему место в `ParamBar`.
- Уже 820px колонка прячется, шапка получает кнопку «☰».
- Потребитель передаёт список разделов с доступностью, историю текущего раздела и содержимое трёх зон.

```tsx
</AppShell>
```
