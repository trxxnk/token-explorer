Поле с подписью и объяснением: текст, число, ползунок, выпадающий список, флажок.

- Обёртка `label.te-field`: подпись в `span` (значение ползунка — в `b` справа), элемент ввода, затем `small` с объяснением простыми словами.
- `te-input` — текст, число, `select`, `textarea`; `te-input--mono` для токенов и адресов. Контур `line-strong`, фон `bg`.
- `te-range` — ползунок; текущее значение всегда показано числом.
- `te-check` — флажок с пояснением во второй строке.
- Результат проверки пиши в `small.is-ok` или `small.is-err` словами; одного цвета недостаточно.
- Потребитель задаёт подпись, значение, границы и текст объяснения. Объяснение обязательно для всего, что названо термином (Top-P, seed).

## Пример

```tsx
<Field label="Температура" value={t.toFixed(2)}
  hint="Чем выше, тем чаще модель берёт не самый вероятный токен.">
  <Range min={0} max={2} step={0.05} value={t} onChange={e => setT(+e.target.value)} />
</Field>
```
