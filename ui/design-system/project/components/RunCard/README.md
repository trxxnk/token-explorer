Карточка прогона — единый шаблон «прогон и разбор» для ответа в чате, решения и будущих разделов.

Части сверху вниз; пустые пропускаются, порядок не меняется:

| Часть | Класс | Что в ней |
|---|---|---|
| Кто и что | `te-run__meta` | `Mark`, модель, номер прогона или ветки |
| Запрос | `te-run__q` | Вопрос стилем `question` (в чате — сообщение пользователя выше) |
| Вывод | `te-run__lead` | `VerdictTag` с фразой и одна главная цифра |
| Этапы | `StageChain` | Как получился результат |
| Результат | `te-answer` или `te-rows` | Текст с `TokenChip` либо список `CandidateRow` |
| Проверка | `Card` + `HeatTable` | Появляется после действия «Проверить» |
| Подробности | `details.te-more` | Точный промпт и сырые данные, свёрнуты |
| Итоги | `te-run__foot` | Время, размер, действия над прогоном |

- Сначала ответ и одна цифра, глубже — по клику: всё ниже вывода можно свернуть.
- Потребитель передаёт данные прогона; раздел определяет, какие части заполнены.
- Карточка лежит на `bg` без рамки и не шире `w-thread`; прогоны в ленте разделяет `space-32`.
- Новый раздел не заводит свою карточку результата — он заполняет эту.

## Пример

```tsx
<RunCard model="Qwen3.5-0.8B-8bit" question="Какое слово лишнее?" value="38%"
  verdict={<Verdict tone="low" label="Ответ ненадёжен">…</Verdict>}
  stats={[{ value: '0.13', label: 'с' }]}
  actions={<Button size="sm">Взять за основу</Button>}>
  <StageChain … />
  <CandidateList options>…</CandidateList>
</RunCard>
```
