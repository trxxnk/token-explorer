# ui — компоненты нового интерфейса и дизайн-система

Здесь лежит задел для редизайна Token Explorer: набор компонентов на React и TypeScript и всё, из чего собирается дизайн-система. Работающий интерфейс по-прежнему `index.html` в корне; эта папка на него не влияет.

Дизайн-система опубликована как страница claude.ai: https://claude.ai/artifact/DTjz29eenMSWXeBmMer9p8 (приватная, открывается только владельцу).

## Что где

| Путь | Что это |
|---|---|
| `src/` | Компоненты: `base.tsx` (кнопки, поля, карточки), `analysis.tsx` (вердикт, токен, строка кандидата, этапы, теплокарта), `shell.tsx` (каркас, выбор модели, карточка прогона, панель токена, настройки) |
| `src/styles.css` | Все стили одним файлом на CSS-переменных; классы с приставкой `te-` |
| `demos/all.tsx` | Примеры для превью: по одной функции `<Имя>Demo` на карточку |
| `design-system/project/` | То, что публикуется: `tokens.json` (цвета, шрифты, отступы), `README.md` (руководство), описания компонентов, обложка, логотипы |
| `build.mjs` | Сборка |

## Команды

Нужен Node 20 или новее. Пакеты ставятся только сюда, в `ui/node_modules` (около 38 МБ).

```bash
npm install
```

```bash
npm run build
```

Сборка проверяет типы, собирает компоненты в один файл `bundle.js`, выписывает типы в `index.d.ts`, копирует исходники и стили и для каждой карточки пишет `preview.html`. Всё это попадает в `design-system/project/components/` и в git не входит: пересоздаётся командой.

Только проверка типов:

```bash
npm run check
```

## Как менять

- **Цвет, размер, отступ** — в `design-system/project/tokens.json`. В `styles.css` значения берутся только через переменные (`var(--accent)`), чисел цвета там быть не должно.
- **Компонент** — в `src/`, пример к нему — в `demos/all.tsx`, описание — в `design-system/project/components/<Имя>/README.md`.
- **Новая карточка** — добавить `<Имя>Demo` в `demos/all.tsx`, строку в `CARDS` в `build.mjs` и `README.md` в папку карточки.

## Публикация

Публикует ИИ-агент через инструмент Artifact: корень — `ui/design-system`, отправляются только изменённые файлы под `project/`. Файлы `.ts` и `.tsx` отправляются с типом `text/plain`. Логотипы загружены отдельно, их номера записаны в `design-system.json`; этот файл отправляется последним и только если менялся.

Значения, изменённые прямо на странице дизайн-системы, сюда сами не попадают: перед правкой `tokens.json` стоит свериться со страницей.
