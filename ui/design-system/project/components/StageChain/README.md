Цепочка этапов: как из всех кандидатов остались немногие, с числом выживших на каждом шаге и объяснением выбранного этапа.

- `te-stages` — кнопки `te-stage`: название (`b`), параметр (`i`), число оставшихся (`span`). Между этапами знак `›`.
- Выбранный этап — `aria-pressed="true"`. Выбран всегда ровно один; по умолчанию — последний («Итог»).
- Под цепочкой — `te-explain` фиксированной высоты `h-explain`: абзац простыми словами (термин жирным, затем что он делает и «было → осталось») и блок `te-fx` с формулой и примером на текущем токене.
- От трёх до шести этапов. В «Разговоре» — Модель → Штраф → Top-K → Top-P → Min-P → Итог; в «Выборе из вариантов» — три этапа. Новый раздел описывает свои шаги этой же цепочкой.
- Выключенный этап из цепочки убирай, а не показывай серым.
- Потребитель передаёт этапы (название, параметр, число, текст, формула, пример) и обработчик выбора; список `CandidateRow` под цепочкой перестраивается под выбранный этап.
- Кнопка «показать по шагам» в шапке блока проходит этапы по очереди.

## Пример

```tsx
<StageChain label="Этапы отбора" active={stage} onSelect={setStage} stages={[
  { id: 'top_p', name: 'Top-P', param: '0.95', count: 22,
    text: 'Идёт от лидера вниз и берёт токены, пока их сумма не наберёт 95%.',
    formula: 'p₁ + … + pₙ ≥ 0.95', example: '·атмос: 30.9% → 32.5%' },
  …
]} />
```
