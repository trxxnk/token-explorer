Знак Token Explorer: три убывающих столбика. Высокий — выбранный токен, два ниже — кандидаты, которые модель могла взять вместо него.

- `token-explorer-mark-on-dark.svg` — для тёмного фона (`bg`, `panel`, `panel2` тёмной темы): высокий столбик `#e4e8f0`, остальные `#8291ff`.
- `token-explorer-mark-on-light.svg` — для светлого фона: высокий столбик `#18202e`, остальные `#3346d3`.
- `token-explorer-app-icon.svg` — значок приложения и вкладки: знак на плашке `#141a24` со скруглением.

Внутри интерфейса используй компонент `Mark`: он берёт цвета из темы. Файлы — для мест вне интерфейса: значок вкладки, README, обложки.

Не меняй число и порядок столбиков, не перекрашивай в цвета состояний, не ставь знак на заливку `accent`. Свободное поле вокруг — не меньше ширины одного столбика.
